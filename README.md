# ATMMachine
An ATM model for Fukuoka needs to be built. The balance can never be changed directly from outside the class - it can only be changed through a validated withdrawal, which the customer can do from the live menu of the terminal.
<br>
Topics Covered:
<br>
1. Classes and Objects
2. Constructor (__init__)
3. Encapsulation and Private Attributes
4. Instance Methods
5. while Loop
6. User Input (input())
7. Conditional Statements (if-elif-else)
8. Exception Handling (try-except)
9. Docstrings
10. Main Guard (if __name__ == "__main__")
